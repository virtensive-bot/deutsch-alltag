# Learning design: what we borrow from the best apps

| App | What it does best | What we take |
|---|---|---|
| **Duolingo** | One clear path, small lessons (3–5 min), lots of tapping instead of typing, mistakes come back at the end, streak and daily XP goal | The path map with units and locked lessons; word-tile sentence building; matching pairs; wrong answers re-queued; daily XP goal |
| **Babbel** | Real-life dialogues, 2–3 new phrases at a time, practised straight away, short grammar tips in context | New phrases introduced in pairs, then practised; every unit ends in a real dialogue ("pick the right reply"); one tip per lesson |
| **Pimsleur** | Audio first: hear → repeat → recall; spaced recall inside one lesson | Every new phrase is heard first and repeated out loud; earlier phrases return inside later lessons |
| **Busuu** | Units tied to real situations, checkpoint tests | One unit per real situation (bakery, train…), with a unit test at the end |
| **Language Transfer / Michel Thomas** | Explain the logic so you can build sentences yourself | A one-line "why" tip per lesson (e.g. why "einen Kaffee") |
| **Memrise / Anki** | Spaced repetition | Finished-lesson phrases enter the review queue and come back right before you forget them |
| **Speak / Duolingo Max** | AI conversation practice | AI role-play unlocks only after the unit is done, in Supportive mode |

## Principles

1. **Recognise before you produce.** Order of difficulty: hear and see it → pick the meaning → build English from tiles → build German from tiles → reply in a dialogue → (later) type or speak freely.
2. **Small steps.** 5–6 new phrases per lesson, introduced two at a time. Lessons take about 5 minutes.
3. **No punishment.** No hearts. A mistake shows the right answer and the exercise comes back at the end of the lesson.
4. **One path.** You always know the next step. Locked lessons can still be opened if you want to skip ahead.
5. **Real goals.** The units follow the original goals: survival phrases → shops → transport → restaurant → her friends → small talk.
6. **Audio optional.** "Can't listen now" turns listening exercises into reading ones, so a lesson still works on the bus.
